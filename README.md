# Discounted Cash Flow (DCF) Valuation Model

## Project Overview
This repository contains a comprehensive 5-year **Discounted Cash Flow (DCF) Valuation Model** built from scratch in Microsoft Excel. The model projects future financial performance, calculates Unlevered Free Cash Flows (FCFF), determines the company's Weighted Average Cost of Capital (WACC), estimates Terminal Value via the Perpetuity Growth Method, and derives an Implied Share Price.

---

## Key Features & Structure
-Revenue & Expense Forecasting:** Projected line-by-line income statement drivers based on historical operating trends.
-Working Capital & Fixed Assets Schedules: Modeled Days Sales Outstanding (DSO), Days Inventory Outstanding (DIO), and Days Payable Outstanding (DPO) to forecast Net Working Capital (NWC), alongside a dedicated CapEx and D&A schedule.
-Unlevered Free Cash Flow (FCFF): Derived NOPAT and adjusted for non-cash items, capital expenditures, and working capital changes.
-WACC & Terminal Value: Discounted explicit cash flows using WACC (6.2%) and estimated long-term value using the Gordon Growth Model (3.0% Perpetual Growth Rate).
-Implied Equity Value & Share Price:** Converted Enterprise Value into Equity Value and derived per-share intrinsic value.
-2-Way Sensitivity Analysis: Built dynamic Excel data tables evaluating Share Price sensitivity across varying WACC and Growth Rate assumptions.
